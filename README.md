# pro-video-editor

A Claude skill that teaches Claude to edit videos like an experienced editor using ffmpeg: strong hooks, pacing, animated captions and titles (ASS/libass), color grading, honest enhancement and upscaling, music ducking, sound design, and platform-ready exports.

Copy `SKILL.md` into your skills folder (for example `.claude/skills/pro-video-editor/SKILL.md`).

Note: upscaling cannot add real detail; the skill defaults to clean 4K and treats 8K as opt-in.
